# BusinessCOOL — лендинг куратора (статический сайт)

Это простой одностраничный сайт, который можно открыть **локально** (двойной клик) или загрузить на любой хостинг статических файлов.

## Что внутри

- `index.html` — страница сайта
- `Tatjana.jpg` — фото в блоке “Обо мне”
- `img/` — скриншоты кейсов

## Как запустить

### Вариант 1 (самый простой)

Откройте файл `index.html` в браузере.

### Вариант 2 (через локальный сервер, по желанию)

Если хотите открыть как “сайт” по адресу вида `http://localhost:...`:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.
